# Arga Tani Mandiri

> **Note:** Website content and media are currently configured as a client preview (`SITE_INDEXING=off` by default).

## Tech Stack
- **Framework:** Next.js 16 (App Router, TypeScript)
- **UI & Styling:** React 19, Tailwind CSS v4, Lucide Icons

## Getting Started

```bash
npm install
npm run dev
```

For production build verification:

```bash
npm run build
npm run start
```

## Environment Variables

Copy `.env.example` to `.env.local` and configure:

- `SITE_URL`
- `SITE_INDEXING`
